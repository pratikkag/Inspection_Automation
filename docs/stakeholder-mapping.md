# Stakeholder Mapping

| Stakeholder | Responsibilities |
|---|---|
| Project Sponsor | Defines objectives, priorities, and approves deliverables. |
| Salesforce System Administrator | Configures objects, fields, Prompt Builder, page layouts, permissions, and security. |
| Inspection Team | Creates inspection records and reviews AI-generated summaries. |
| Customer Support Team | Uses permitted inspection information to support customer inquiries. |
| Management | Reviews inspection activities and outcomes for decisions. |
| IT Support | Helps maintain availability and resolve technical issues. |
| Project Developer | Implements metadata, tests behavior, and maintains documentation. |
| AI Service (system capability) | Generates a draft summary from supplied record context; it is not a human stakeholder. |
