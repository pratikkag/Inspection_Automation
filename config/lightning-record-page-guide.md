# Lightning Record Page guide

1. In Setup, open **Object Manager → Inspection → Lightning Record Pages** (or open a record and choose Edit Page).
2. Create or edit the Inspection record page with Lightning App Builder.
3. Include Record Detail or Dynamic Forms fields for:
   - Inspection Date
   - Inspection Status
   - Inspector Name
   - Customer Name
   - Inspection Notes
   - AI Summary
4. Add the Prompt Builder/Field Generation component or action as supported by your org's UI.
5. Save, activate, and assign the page to the appropriate app/profile/record type as needed.
6. Test with a user who has the intended permissions.

This is a configuration guide. The record page is not included as deployable metadata in this starter because page assignment and available components depend on the target org.
